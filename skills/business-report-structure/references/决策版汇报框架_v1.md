# 内部高质量决策文档框架

> 来源：内部分享《「激励组」提高交付物质量的方法》+ 2026-09-20 分享会；整理为可分享、可执行的汇报质量 skill。
> 定位：质量层框架，不替代全链路生产流程。

## 一句话标准

交付物不是文档，而是“可直接决策的方案”。决策人看完不需要再追问“你的建议是什么”，即可完成是/否、A/B、金额、时间四类决策之一。

## 思考层：WHY / WHAT / HOW MUCH

### WHY & WHY NOW

| 层级 | 要回答的问题 | 要求 |
|---|---|---|
| 现象 | 发生了什么 | 现象必须有数据 |
| 影响 | 不解决会怎样 | 影响必须说明业务后果 |
| 根因 | 为什么会发生 | 根因必须区分客观环境与机制问题 |

### WHAT：方案 6 要素

1. 方案目标
2. 核心原则
3. 内外感知
4. 方案内容
5. 数据测算
6. 推进计划

激励方案可按 7 要素核查：激励目标、激励对象、激励规则、激励周期、激励预算、核算规则、退出机制。

### HOW MUCH

- 投入：预算多少、从哪里腾挪
- 产出：覆盖多少人 / 占比多少、影响程度、可持续性
- 风险：全链路影响，如长库龄、交付周期延长、竞品反应
- 退出机制：阶段性方案的退出条件和时间

## 呈现层：6 大原则

### 1. 总分总

- 前置「一句话结论 + 背景摘要 + 方案要点 + 收益分析 + 决策点」的方案总览
- 总览只放决策人必须知道的信息，不放推导过程、不堆明细
- 决策人应能在 3 分钟内看懂：现象、根因、方案、收益、决策点

### 2. 结论先行

小标题直接写结论：

- ❌ 方案测算
- ✅ 预计覆盖 75% 目标人群，预算控制在 X 万元以内
- ❌ 市场对标
- ✅ 调整后核心岗位总收入达到行业 P50-P75 水平

### 3. MECE

- 相互独立：两个章节不在回答同一个问题
- 完全穷尽：关键问题没有遗漏归属
- 常用拆法：
  1. 二分法：A / 非 A
  2. 流程法：按前中后、阶段顺序
  3. 要素法：目标 / 对象 / 规则 / 周期 / 预算 / 核算 / 退出
  4. 公式法：成交额 = 客流量 × 客单价
  5. 矩阵法：紧急重要四象限、SWOT
  6. 问题解决链路法：背景问题 → 原因分析 → 方案设计 → 数据验证 → 风险控制 → 推进计划 → 决策事项
  7. 某车企四步法：用户 → 用户需求 → 企业需求 → 目标 OKR

### 4. 定量定性

- 定性回答 Why：挖掘观点背后的原因，不停留在“X% 支持 / Y% 反对”
- 定量回答 How Much：
  - 公司预算：我有多少、花多少、超出部分哪里腾挪
  - 覆盖范围：覆盖多少人、占比多少
  - 精准性：是否覆盖目标人群，头腰尾分布
  - 影响程度：人均收入提升、个体前后差异、同比变化
  - 分布情况：全国 / 门店 / 区域 / 赛道
  - 外部对标：市场分位水平
  - 可持续性：明年后年推演
  - 分场景：90% / 100% / 110% 达成推演

### 5. 内部外部

| 方案要素 | 内部视角 | 外部视角 |
|---|---|---|
| 方案目标 | 核心员工留存率 | 市占率 |
| 内外感知 | 内部一线预期 | 竞品对标 |
| 数据测算 | 头腰尾分布 | 行业薪酬竞争力 |
| 方案内容 | 内部排名 | 竞品表现、交付周期 |

### 6. 一致性

- 颜色一致：一页不超过 3 种强调色；深蓝主色，蓝字中性，绿字正向，橙字风险
- 数据一致：千分位、统一单位、统一口径、统一小数位
- 表格一致：每张表标明单位、时间范围、指标口径、数据来源
- 文案一致：每段超过 10 字，前面必须有 2-8 字摘要并高亮
- 观点数据互撑：每个重要观点至少一组数据支撑；每张数据表都有一句结论；无结论的数据不放入文档

## 10+1 检核清单

1. 开头和结尾是否写了决策点？
2. 是否有方案总览？3 分钟内能否看懂现象、根因、方案、收益、决策点？
3. 小标题是否直接写结论？
4. 关键部分是否 MECE？用了哪种拆解方法？
5. 是否定量定性结合？
6. 是否覆盖内部和外部视角？
7. 颜色、指标口径、单位是否一致？长文案是否有 2-8 字摘要？
8. 每个关键结论是否有数据支撑？每张关键表是否有一句结论？
9. 是否说明投入、产出、风险、边界、退出机制？
10. 决策人是否还会问“你的建议是什么”？

**+1 会后复盘**：重要汇报后在文档后附会议记录，补三类结论：

- **YES**：认可了什么，可复用，沉淀为模板或案例
- **NO**：调整了什么，说明标准尚未统一
- **MORE**：追问了什么，说明材料哪里不够清楚

## 不同汇报对象的关注点

| 对象 | 关注点 | 需准备的支撑 |
|---|---|---|
| 高层 | 方向性、原则性 | 方案目标、核心原则、长期影响 |
| 业务线负责人 | 方案有效性 | 内外感知、执行路径、效果测算 |
| 经营负责人 | 预算与合理性 | 预算推演、市场对标、风险边界 |

## 落地建议

1. 不要求一次套用全部方法；每次报告优先补齐“决策点 + 结论先行 + 每表一句结论”
2. 写完先自查 10 项，再交给人看
3. 重要汇报结束后做 +1 复盘，把 YES / NO / MORE 沉淀回个人模板
